# SYSGO Prototype 1.0

SYSGO (System Governance & Operations) is a terminal-based system management and monitoring application designed to provide administrators and power users with a centralized interface for managing Linux systems.

This release represents **Prototype 1.0**, the first public development version of the project.

## Features

### Network Management

* View available network interfaces
* Basic network configuration management
* Network status monitoring

### System Configuration

* Basic system settings management (work in progress)
* Hardware and operating system information
* Foundation for future administration modules

### Process Monitoring

* Real-time process overview
* CPU and memory usage monitoring
* Process management capabilities
* Interface inspired by modern system monitoring tools

### System Logs

* Browse system logs
* Basic event analysis
* Quick access to diagnostic information

## Project Status

⚠️ This is an early prototype release. Features are under active development and may change significantly in future versions.

## Planned Features

* Service management
* Advanced network configuration
* Firewall and security tools
* Hardware monitoring
* User and permission management
* Administrative dashboard
* Reporting and diagnostics
* Multi-distribution Linux support

## Project Goal

The goal of SYSGO is to create a lightweight, fast, and user-friendly terminal environment that combines essential system administration tools into a single interface, reducing the need to switch between multiple command-line utilities.

# 📖 Installation Guide

## Installation

1. Clone the repository:

   ```bash
   [git clone https://github.com/Michalsonix/SYSGO.git]
   ```

2. Navigate to the project directory:

   ```bash
   cd SYSGO
   ```

3. Run the application using Python:

   ```bash
   sudo python3 autorun.py
   ```

4. Follow the on-screen instructions to complete setup.

> Make sure you have Python 3 installed before running the project.
